NAS folders

Folders Jellyfin can see that hold your artwork. Use the path inside the Jellyfin container (e.g. /artwork), not the NAS share path. See Help for how to add one on a UGREEN NAS.

The basics

  1. Pick a library chip at the top (or Library artwork to change the library tiles themselves).
  2. Click any title to open its artwork editor.
  3. For each slot (Poster, Backdrops, Logo…) you can drag an image onto it, click it to choose a source, or click it and press Ctrl+V to paste.

Four ways to add an image

  • Upload — a file from this computer or phone.
  • Web link — any public image address. Google Drive, Dropbox, OneDrive and Imgur share links are converted automatically. Tip: you can also drag a picture straight from another browser tab onto a slot.
  • NAS — browse or search your artwork folders. Copy stores a copy in Jellyfin; Link points at the NAS file so it's never duplicated.
  • Online — Jellyfin's own providers (TMDB, Fanart.tv, etc., whichever you have enabled).

Library backgrounds

Under Library artwork you'll also find Home page and Login page — add images there for those screens. Backdrops added to a library become the background of that library's page (Settings → Library backgrounds). This works in the browser and in apps built on the web app (Jellyfin Media Player, the Android/iOS phone apps). Native TV apps keep their own behaviour.

Backdrops

Items can have several backdrops. The first one is the "main" one most apps show. Use the star button to make any backdrop the main one, the arrows to reorder, and the + tile to add more.

Doing many at once

Click Select, tick the items, then Apply artwork to put the same image on all of them (handy for season posters or a collection's backdrop).

Adding a UGREEN NAS folder

  1. In UGOS, open Docker → Containers, stop the Jellyfin container and choose Edit.
  2. Under Storage space / Volume, add a folder: pick your artwork folder on the NAS (e.g. /volume1/Media/Artwork) and set the container path to /artwork. Read-only is fine for Copy mode.
  3. Start the container, then here in Settings add a folder named e.g. "UGREEN Artwork" with path /artwork. A green tick means Jellyfin can see it.

Your existing media folders (already mapped for your libraries) can be added the same way — use the same container path your library uses.

Linked images

Linked images show an orange NAS tag. If you later move or rename that file on the NAS, Jellyfin will lose the image. A metadata refresh with "Replace existing images" ticked can also swap them for downloaded ones.
